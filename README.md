Abhishek Patel Portfolio

Files included:
- index.html: Updated portfolio with five project cards and a Samarth eGov demo link on each project.
- styles.css: Stylesheet for the portfolio layout and responsive design.
- script.js: Mobile navigation behavior.

To preview with VS Code Live Server, open the `abhishekpatel-portfolio` folder (the folder containing this README and `index.html`) in VS Code, open `index.html`, then choose **Open with Live Server**. If you open the parent `abhishek_Portfolio` folder instead, the portfolio is nested one level down, so Live Server may show a directory listing instead of the page.

Internet access is needed for the Google Fonts import and Samarth eGov demo links.

Note: The uploaded source did not include assets/Abhishek_Patel_Resume.pdf. The existing Download résumé link points to that path, so add your resume PDF in the assets folder using that exact filename for the download link to work.
